SOUNDSCAPES COURSE WEBSITE

Open index.html in a modern browser. No server is required.

14 independent chapter pages, each designed for 60 minutes:
15 minutes guided reading; 30 minutes practical activity; 15 minutes reflection and knowledge check.

Structure:
- index.html: course home and chapter directory
- modules/module-01.html through module-14.html: independent lessons
- assets/style.css: shared visual design

To add a chapter: copy a module HTML file, edit its content, add a card to index.html and add its link to the chapter navigation. To remove a chapter, remove its file and links. Keep the shared stylesheet path unchanged.

The hardware lesson follows the supplied Hardware Development for Soundscape Device document. The PANNs/BirdNET lesson describes the parallel analysis case study. Model detections should not be presented as verified ecological observations without validation.

Included source material and images:
- resources/Hardware_Development_for_Soundscape_Device.docx: supplied source document.
- assets/hardware_photos/: eight embedded figures and photographs from the source document, used in Chapter 05.
